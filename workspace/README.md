# Marinara Engine — рабочий проект

Это рабочая папка для кампании **The Pentad Bureau** в Marinara Engine. Здесь собраны импортируемые материалы кампании, настройки подключений, пресеты, резервная копия, актуальные патчи и документация по серверному развёртыванию.

Проект не является исходным кодом Marinara Engine. Исходники и развёртывание живут на сервере; эта папка — структурированное хранилище конфигурации, лора и эксплуатационных материалов.

Материалы также зеркалируются в папку `workspace/` репозитория Marinara Engine через отдельную ветку и PR. Локальный ZIP-бэкап не публикуется в Git из-за размера; его контрольная сумма хранится в `backup/README.md`.

## Начни отсюда

Если ты впервые работаешь с проектом, прочитай документы в таком порядке:

1. [CURRENT_STATE.md](CURRENT_STATE.md) — текущая задача, последние решения и точка продолжения.
2. [CONTENTS.md](CONTENTS.md) — полная карта файлов и папок.
3. [AGENTS.md](AGENTS.md) — обязательные правила работы и документирования.
4. [TECHNICAL_INFO.md](TECHNICAL_INFO.md) — репозиторий, сервер, Docker, сеть, модели и команды сопровождения.
5. [RUNBOOK.md](RUNBOOK.md) — диагностика, обновление, откат и безопасность сервера.
6. [PATCHES.md](PATCHES.md) — статус и порядок работы с серверными патчами.
7. [WORLD_GUIDE.md](lore/The-Pentad-Bureau/WORLD_GUIDE.md) — устройство и правила мира кампании.

## Кампания The Pentad Bureau

The Pentad Bureau — приключенческий стимпанк-детектив в городе **Alderwick**. В центре — независимое хартированное Бюро расследований и пять его основных функций: руководство, полевая работа, социальная разведка, аналитика и нестандартный доступ.

Для работы с миром используй [WORLD_GUIDE.md](lore/The-Pentad-Bureau/WORLD_GUIDE.md) как краткий канон. Он определяет атмосферу, институты, социальные правила, технологические ограничения и принципы создания новых дел. Конкретные расследования, второстепенные персонажи и организации должны возникать из игры и становиться постоянным лором только при повторяющейся ценности.

## Серверное развёртывание

| Параметр | Значение |
| --- | --- |
| Сервер | `comfy-server` |
| Каталог исходников | `/srv/marinara/Marinara-Engine` |
| Репозиторий | `babichandrei-cell/Marinara-Engine` |
| Ветка | `staging` |
| Запуск | Docker Compose с локальной сборкой образа |
| Контейнер | `marinara-engine-marinara-1` |
| Локальный доступ | `http://192.168.1.27:7860` |

Полные технические сведения, включая текущий commit, версию, модели, внешний туннель и безопасные команды обновления, находятся в [TECHNICAL_INFO.md](TECHNICAL_INFO.md).

## Модели и backends

- Текстовая генерация: `llama.cpp` с моделью `Gemma-4-The-Deckards-Brain-31B-NVFP4`.
- Embeddings: `BGE-M3-Q8`.
- Генерация изображений: ComfyUI с `KREA2/krea2_turbo_int8_convrot.safetensors`.

Экспорты этих подключений находятся в `connections/`. Адреса и чувствительные параметры не следует менять без сверки с текущей конфигурацией сервера.

## Рабочие правила

- Не записывай в репозиторий или документацию пароли, SSH-ключи, API-ключи, токены и содержимое `.env`.
- Перед изменением серверной части сверяй состояние с `origin/staging` и проверяй [TECHNICAL_INFO.md](TECHNICAL_INFO.md).
- В корне `patches/` должны оставаться только актуальные патчи. Устаревшие версии перемещай в новую датированную подпапку `patches/archive/`, а не удаляй.
- При добавлении или перемещении материалов обновляй [CONTENTS.md](CONTENTS.md).
- При изменении устойчивых правил мира сначала обновляй [WORLD_GUIDE.md](lore/The-Pentad-Bureau/WORLD_GUIDE.md), затем соответствующий импортируемый лорбук или карточку.
- При обновлении сервера, откате, инциденте или применении патча следуй [RUNBOOK.md](RUNBOOK.md) и фиксируй результат в [CURRENT_STATE.md](CURRENT_STATE.md).
- Не превращай мир в энциклопедию заранее: новый постоянный лор нужен только при повторяющихся противоречиях, слабой генерации или появлении важной повторяющейся сущности.
