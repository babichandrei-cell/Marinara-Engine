## Сейчас

- **Активная задача:** серверные патчи Roleplay Storyboard и World Maps синхронизируются с GitHub через отдельный PR в `staging`.
- **Обсуждение:** live llama.cpp-лог подтвердил исчерпание прежнего 2200-token лимита Storyboard planner; новый патч повышает budget до 4096 и объясняет fallback при неполном JSON.
- **Точка продолжения:** после merge продолжать обычное наблюдение за Storyboard; при fallback сравнить `n_gen` в llama.cpp с лимитом 4096.

- **Задача:** подготовить и развернуть набор серверных патчей Roleplay Storyboard.
