## Безопасная проверка патча

Выполняй на сервере из `/srv/marinara/Marinara-Engine`:

```bash
git branch --show-current
git rev-parse --short HEAD
git status --short

# Проверка прямого применения: ничего не меняет.
git apply --check /путь/к/patches/имя-патча.patch

# Если прямое применение не проходит, проверка обратного применения покажет,
# не присутствует ли это изменение уже в коде.
git apply --check -R /путь/к/patches/имя-патча.patch
```

Интерпретация результата:

- прямая проверка проходит — патч можно рассматривать для применения после ревизии;
- обратная проверка проходит — изменение уже присутствует, повторно не применяй;
- обе проверки не проходят — контекст изменился: сравни патч и текущий код вручную.

## Порядок работы с новой доработкой

1. Сначала запиши цель и целевой commit в `CURRENT_STATE.md`.
2. Создай или обнови патч только после проверки изменения на серверной ветке.
3. Зафиксируй в этом файле: назначение, затронутые файлы, базовый commit, способ проверки и итоговый статус.
4. После появления следующего актуального варианта перемести старый в `patches/archive/YYYY-MM-DD/`.
5. Не удаляй архивы без отдельного решения пользователя.
